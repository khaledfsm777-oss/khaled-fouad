 منظومة البنيان الرقمي للقرآن الكريم - النسخة المكتبية المستقلة (Windows)
 إعداد وبحث: الباحث خالد فؤاد السيد
========================================================================

هذا البرنامج مستقل تماماً ويعمل بدون إنترنت وبدون الحاجة لتثبيت أي برامج وسيطة مثل Node.js أو غيرها.

طريقة التشغيل:
1. انقر نقراً مزدوجاً على الملف:
   "منظومة البنيان الرقمي للقرآن الكريم.exe"
   أو الملف المساعد:
   "تشغيل_البرنامج.bat"

2. لإنشاء اختصار على سطح المكتب:
   - اضغط بزر الفأرة الأيمن على ملف "منظومة البنيان الرقمي للقرآن الكريم.exe"
   - اختر: إرسال إلى (Send to) -> سطح المكتب (إنشاء اختصار) (Desktop (create shortcut)).
   - سيعمل البرنامج مباشرة من سطح المكتب أو من أي مجلد تضعه فيه.

التوافق:
- متوافق مع Windows 11, Windows 10, Windows 8.1, Windows 8, Windows 7 (32-bit و 64-bit).
